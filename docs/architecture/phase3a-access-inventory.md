# Phase 3a public access inventory

Base: Phase 2 `8489abec615c8f8febb19cf56e079f661b6f4196`. All 295 public Convex query/mutation/action registrations are listed below (294 previously used the maintenance-only raw-named seam; `messaging/chat.sendMessage` already used `guestMutation`). Internal seed/worker functions retain their internal builders. HTTP handlers retain the maintenance-gated `httpAction` seam and existing signature/token contracts.

Maintenance runs before every public trust check and every HTTP handler. `admin*` means the existing operations policy, including managers. Owner-only endpoints use `staff*` with `manageTeam`. Marketing uses separate permission builders because a marketing grant need not include any staff role. `authenticated*` checks Clerk identity but does not require staff; record history dispatches its narrower policy by entity type. Actions use the authoritative helper’s internal access query under the caller identity, never caller-supplied identity or direct database access.

Guest builders require a matching hashed token on a web conversation in the same transaction. Missing optional legacy credentials still fail with `INVALID_GUEST_TOKEN`. Device builders resolve the hashed display token; invalid/revoked devices receive the existing unpaired/no-op result. Pending devices can only read their own unexpired pairing code. Public capability endpoints keep booking access tokens, signed proposals, one-use handoffs and lease cleanup checks in their handlers.

The inventory test compares every source registration with this table and requires explicit public reasons and staff/marketing policies. The source gate also detects aliased raw imports, raw reexports and generated-server namespace imports. No Phase 3 completion is claimed.
