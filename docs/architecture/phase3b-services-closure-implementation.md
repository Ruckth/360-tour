Services owns services, staff, roster/time off, appointments and appointment money. All **381 public/internal registrations** retain their original module paths, names, builders, validators, capabilities/reasons, args/return contracts and handler bodies. All ten HTTP action declarations and HTTP route composition also remain unchanged. There are **zero renamed, added or removed RPC registrations**. Public inventory stays **295 explicit / 0 raw**.

No endpoint registration is imported or re-exported by model; there are no proxy endpoints, compatibility aliases or duplicate implementations. Cross-domain work still uses the caller's actual ctx in one transaction, with no new ctx.runMutation boundary or authorization bypass.
