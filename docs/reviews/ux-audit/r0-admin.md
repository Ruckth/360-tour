# Round 0 · admin screens: settings, team, coupons, marketing dashboard

Graded against [scorecard-rubric.md](scorecard-rubric.md) and [visual-brief.md](visual-brief.md). Screenshots are from `docs/screenshots/audit-r0/` (iPad 1180×820, phone 390×844, desktop 1440). Anything a screenshot can't show (dirty, saving, error, read-only, focus, target sizes, labels) was read from the code: `AdminSettingsView.tsx`, `TeamSettings.tsx`, `marketing/CouponEditor.tsx`, `marketing/dashboard/*`, `ui/{stat,toggle-group,time-picker,card,button,input,select,info-tip}.tsx`.

**Area average: 8.05 / 10.** No screen reaches 9 in every category. The brief's structure has landed: four Cards, a Stat tile, a dirty-only Save bar, a serif title, 15/13 person rows. What keeps the scores down is states (lost drafts, a Saved message nobody sees), layout holes (an empty grid cell, an empty column) and copy that has to be decoded.

## Below 9, by impact

1. **Business · States · 6.** Draft is lost silently on tab switch; "Saved" lands off screen; no Discard. Fix: confirm on dirty tab change plus `beforeunload`, keep the bar for 2.5s with "✓ Saved", add a ghost Discard.
2. **Team · Clarity · 7.** "Invited · 26 Nov" is really the expiry date; "Marketing Marketer"; switch meaning hidden in a column header. Fix: "Invite expires 26 Nov", label marketer as "Editor", a Cashier\|Manager segmented control per rule.
3. **Dashboard · Clarity · 7.** Jargon, three explanation layers, Unknown vs Not tracked. Fix: plain labels, remove the ? button, one name for the bucket, shorter context line.
4. **Dashboard · Layout · 7.** Empty KPI cell and stretched tile. Fix: `[&>*:last-child]:col-span-2` on the tile grid, Add spend inline.
5. **Coupon · Layout and Responsive · 7.** Empty aside column on iPad. Fix: conditional `lg:grid-cols-[…_22rem]` and `max-w-3xl` until the Summary exists.
6. **Business · Efficiency · 7.** Free-text currency and time zone; 5-tap time change. Fix: Select or Combobox, one 30-minute slot Select, Discard.
7. **Team · Layout · 7.** Change column misaligned. Fix: always reserve the `size-11` menu slot, plus a spacer for the owner row.
8. **Team · Consistency · 7.** No tab title, older header-bar Cards, native selects. Fix: `Panel grouped` across all Settings tabs, `ui/select`.
9. **Business and Team · Responsive · 8.** Clipped tab row. Fix: overflow fade mask in `SegmentedTabs`.
10. **Coupon · Typography · 8.** Bold placeholders. Fix: `placeholder:font-normal placeholder:text-muted-foreground/70`.
11. **Dashboard · States · 8.** Skeleton doesn't match the layout. Fix: mirror the hero plus tiles grid.
12. **Dashboard · Responsive · 8.** Three toolbar rows on phone. Fix: View options into ⋯, segmented control and ⋯ on one row.
13. **Dashboard · Consistency and Typography · 8.** Mixed segmented shells; lowercase legend; 11px axis. Fix: `variant="segmented"`, `utmSourceLabel`, `text-xs`.
14. **Business · Consistency, Color, Clarity, Layout, A11y · 8.** Tabs in mixed styles; faint read-only inputs; key description hidden; orphaned status; time button announces no value. Fixes in the table above.
15. **Team · Color and States · 8.** Faint off-switch; role-change message off screen. Fix: stronger off track, inline per-row status, Discard.
16. **Coupon · Hierarchy, Consistency, Efficiency, Clarity, A11y · 8.** Detached primary; two radio styles; draft hidden in ⋯; "500" unitless; 40px radio labels. Fixes in the table above.
